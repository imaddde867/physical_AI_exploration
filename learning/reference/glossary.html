Glossary

Used consistently across lessons.

MCUMicrocontroller: a tiny computer on one chip. Here the RP2040.
SRAMWorking memory, 264 kB in six banks. Lost on power-off.
FlashSeparate chip storing firmware and files; RP2040 reads it over QSPI (XIP). Size unverified (4 vs 16 MB).
clk_periClock feeding SPI/UART. MicroPython default 48 MHz unless set with machine.freq.
CASET / RASET / RAMWRST7789 commands: set column range, row range, begin writing frame memory.
REPLInteractive Python prompt over USB serial.
BusWires plus a protocol for chips to talk.
SPIFast bus used for the screen. Pins: SCK clock, MOSI data, CS select, plus DC.
I2CSlow two-wire shared bus (touch, motion sensor); devices have addresses.
GPIOGeneral-purpose pin you set high/low or read.
FramebufferRAM array holding the next image. 134,400 bytes here.
RGB56516-bit colour: 5 red, 6 green, 5 blue bits.
DC / CS / RST / BLScreen pins: data-or-command, chip select, reset, backlight.
UF2 / BOOTHold BOOT while plugging in; board appears as drive RPI-RP2; drop a .uf2 firmware file on it.
MicroPythonPython runtime that runs on the MCU. Files main.py run at power-up.
